# Sistema de Matrícula em Java | Java Enrollment System

Sistema simples de matrícula desenvolvido em Java para praticar orientação a objetos, validação de dados e manipulação de arquivos.

Simple enrollment system developed in Java to practice object-oriented programming, data validation, and file handling.

---

## Funcionalidades | Features

* Cadastro de alunos via terminal
* Validação com Regex
* Manipulação de arquivos `.txt`
* Uso de Java NIO (`Path`, `Files`)
* Escrita de arquivos com `FileWriter`

---

## Tecnologias | Technologies

* Java
* Scanner
* Regex
* FileWriter
* Java NIO
